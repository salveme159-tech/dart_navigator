# 2026-10-08 외부 검토 대응 기록

## 이번 패치에서 실제 수정한 코드

- `server/dart/engine.ts`: 재무상태표 소계·총계 재조정에 더해, 미분류 차입금/사채/금융부채 행 및 XBRL 차입금 ID를 감지하면 순차입금 계산을 거부합니다. 재무상태표가 완전해도 부채 분류가 불완전하면 0으로 간주하지 않습니다.
- `server/dart/engine.ts`: 공시상 존재하는 계정의 금액이 비어 있으면 누락 입력으로 간주해 거부합니다.
- `server/dart.test.ts`: 위 두 실패 사례를 회귀 테스트로 추가했습니다.

## 기존 제출본에서 이미 확인할 수 있는 코드 규칙

- IS/CIS/CF 누적 조회에 `thstrm_add_amount`가 없으면 3개월 값으로 조용히 대체하지 않습니다.
- 3분기는 기본 3개월, `3분기 누적`은 누적으로 해석합니다.
- 재무상태표 자산/부채/자본 및 유동·비유동 소계를 재조정합니다.

## 검증 상태와 한계

- 위 테스트는 추가되었으나 이 작업 환경에서 의존성 전체 설치 및 Vitest 실행은 확인하지 못했습니다. 테스트 통과로 표시하지 않습니다.
- 재무상태표 항등식만으로 개별 계정의 완전성을 증명할 수 없습니다. 미분류 차입성 계정에 대한 방어는 강화했지만 모든 비표준 XBRL taxonomy를 포괄한다고 보장하지 않습니다.
- 2026년 대한전선 반기 원문과 핵심 지표의 수작업 대조, 실제 브라우저 E2E, `pnpm check/test/build`, 키 유출 테스트는 배포 전 별도 게이트입니다.
- 공모전 심사에 제공하는 체험 데이터는 원문으로 독립 검증된 스냅샷만 `검증됨`으로 표시해야 합니다.

## 배포 전 실행

pnpm install --frozen-lockfile
